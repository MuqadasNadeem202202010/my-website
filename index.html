Projects

GeoSense AI

A GIS-based web application built to explore how mapping, location intelligence and interactive web apps work together. Users can search locations, upload and visualize shapefiles, select and highlight features, explore and search attribute tables, export data as CSV or GeoJSON, compare route distances, and view weather and country information. It offers four map layers (Street, Satellite, Topographic and Dark) and a responsive interface.
